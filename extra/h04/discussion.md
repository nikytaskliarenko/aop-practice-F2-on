# Практична 4. Булева алгебра та бітові операції.

## Частина 4. Відкрита дискусія

### Навіщо в програмуванні окремий тип для «так» і «ні»?
Тип boolean має лише два значення: true і false. Без нього, як у C, істиною вважається будь-яке ненульове число, і
компілятор пропускає помилку if (x = 0).

### Як сказати !(a && b) людською мовою?
"Неправда, що a і b істинні одночасно", тобто хоча б одне з них хибне.

### Чим && відрізняється від &?
&& працює тільки з умовами, а & працює і з boolean, і з цілими числами.

### Чому програма не падає в if (x != null && x.name == "Іван"), хоча x порожній?
Якщо x == null, то ліва частина хибна, і && вже знає, що вся умова хибна, тому права частина не виконується.

### Як запхати 32 відповіді «так/ні» в одне число?
В кожен в біт ми можемо записати 0 - ні або 1 - так.

### Що швидше: n % 2 чи n & 1?
n & 1 швидше, бо бітова операція виконується процесором за один такт.
